# Security Policy

## Supported Versions

| Version | Supported |
| ------- | ----------------- |
| 0.1.x   | :white_check_mark: |
| < 0.1   | :x:               |

## Reporting a Vulnerability

If you find a security vulnerability in this project, please report it by sending an email to **emreozabay629@gmail.com**. Do not open a public issue for security vulnerabilities.
